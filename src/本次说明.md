# 电子礼簿系统PRO V3.8.10 HTML纯浏览器语音最终验证版

## 本次锁定目标
- 不改变现有主界面、礼簿背景、礼簿内容结构、打印排版、封面、总计页。
- 本版本以 HTML 浏览器版作为语音最终验证基准，暂不涉及 EXE 语音转换。

## 语音
- 播报格式固定为：`{姓名}，{收礼方式}送礼，{金额}元。`
- 例：`张三，微信送礼，500元。`
- 播报顺序：提示音完整播放结束 → 短暂事件循环让渡 → speechSynthesis 立即播报。
- 首选 Google 普通话（中国大陆），失败后自动尝试可用的 Microsoft Kangkang / Yaoyao / 其他中文语音。
- 不再使用 Microsoft Huihui 作为候选优先项。
- 不在每次播报前无条件 cancel，避免 `cancel()` 造成 interrupted/synthesis-failed。
- 等待浏览器 voiceschanged，防止语音列表尚未初始化导致失败。
- 每个候选语音失败后自动短暂重试。
- 支持设置音量、语速、播报模板。
- 删除“语音播报起报金额”设置；所有有效录入默认播报。

## 副屏
- 主屏设置中的“局域网副屏投送”不再提供“请使用局域网 HTTP 地址打开 HTML”的输入框。
- 改为只读的本机 HTTP 地址显示 + 复制按钮。
- 地址按当前 HTML 实际访问来源生成；纯 `file://` 打开时不会伪造一个不可用的 IP/端口。
- 主屏事项上传的收款码会同步传给副屏。

## 重要技术边界
纯浏览器 HTML 本身不能监听 TCP/HTTP 端口，也不能凭空启动局域网服务器。因此跨设备电视投送的真正 HTTP 服务端需要由后续 HTML→EXE 宿主或现有 HTTP 服务提供。本版本不伪造 IP/端口，先确保浏览器语音链路稳定。

## V3.8.11 HTML纯浏览器副屏与语音调整
- 不改变现有礼簿系统界面、背景、内容结构。
- 语音音量、语速、自定义播报样式移动到“语音播报音色”正下方。
- 删除语音起报金额相关设置（如存在则不再使用）。
- 播报模板默认：{name}，{type}送礼，{amount}元。；支持直接编辑模板。
- 提示音 ended 后不再人为增加 60ms 停顿，立即进入 SpeechSynthesis。
- 副屏收款码：副屏收到 paymentQr 后直接显示，不再受旧布局隐藏条件影响。
- 局域网副屏：设置项不再出现“请先用本机HTTP服务打开 index.html”输入/提示；自动尝试识别本机局域网 IPv4，并显示 HTTP 地址+默认端口 8080，可复制。
- 说明：纯浏览器 file:// 页面本身不能监听 HTTP 端口；真正让手机/电视通过 IP:8080 访问，需要页面由本机 HTTP 服务提供。HTML 版只负责自动生成并显示地址，不伪造可用服务。

## V3.8.12 本次严格修正
1. “语音播报参数”和“自定义播报样式模板”移动到左侧“语音播报音色”正下方；右侧不再放这两个模块。
2. 局域网副屏地址改为“只显示、不填写”的地址展示块，不再显示“本机局域网IP”假占位；默认端口固定 8080，浏览器能取得局域网 IPv4 时直接显示可复制地址，取不到时明确提示浏览器隐私限制，不伪造 IP。
3. 副屏收款码同步修正：主屏事项中的 paymentQr 推送后优先显示；不再被副屏本地旧布局缓存覆盖。
4. 副屏去掉多余的“设置”按钮及其页面依赖，仅保留投屏展示与全屏控制。
5. 提示音改为浏览器 WebAudio 生成的短提示音，不再依赖 voice-prompt.wav；提示音结束后立即进入中文语音播报。这样本地 HTML、浏览器和后续 EXE 都不依赖额外音频文件路径。
6. 未改动礼簿表格、打印、封面、总计页、录入字段等其它确认内容。

4. 未识别到 IP 时不伪造地址，不显示“本机局域网IP”这种占位地址。
