# 电子礼簿系统PRO V3.8.10

HTML纯浏览器语音最终验证版。

先直接打开 `index.html` 验证：
1. 语音开关开启；
2. 设置事项 → 语音预览；
3. 实际录入 → 确认提交；
4. 应听到“提示音 → 张三，微信送礼，500元。”；
5. 设置事项中的语音音量、语速、播报模板可调整；
6. 副屏收款码可从主屏事项设置同步给副屏。

本版本不包含 EXE 打包文件，后续以本 HTML 作为转换基准。

### V3.8.11
本版继续以 HTML 纯浏览器验证为基准，不改变礼簿主界面、背景和内容结构。语音设置统一放在“语音播报音色”下方；提示音结束后立即调用浏览器 SpeechSynthesis；副屏收款码强制同步显示；局域网副屏设置自动识别本机局域网 IP 并生成 `http://IP:8080/guest-screen.html` 地址供复制。注意：纯 `file://` HTML 无法自行监听 HTTP 端口，手机/电视访问该地址必须有本机 HTTP 服务在对应端口提供页面。

V3.8.12：严格针对副屏与语音链路修正，不改礼簿/打印结构。语音参数与模板移至左侧音色下方；副屏地址仅显示并可复制；修正事项收款码同步；副屏移除多余设置入口；提示音改为 WebAudio 短提示音并紧接中文播报。
